# 植物大战僵尸(概念版) 运行指南



## 游戏启动
运行 `main.py` 文件开始游戏



## 登录游戏

登陆游戏后，您的游戏得分将会计入排行榜



## 难度选择
游戏提供三种难度模式：
- 简单模式

- 中等模式  

- 困难模式

  

## 所需依赖库
安装以下 Python 库：

```bash
pip install pillow
pip install pygame
pip install numpy
```



## 项目结构

植物大战僵尸(概念版)/
├── main.py          # 主程序入口

├── game2/           # 游戏模块2
